# Git Fundamentals Lab

## Objective

Complete the following tasks to practice basic and essential Git operations. By the end of this lab, you should be able to:
- Create and manage branches.
- Commit changes and understand commit history.
- Rebase branches and resolve conflicts.
- Push changes to a remote repository.
- Create pull requests and participate in code review workflows.

## Prerequisites

- Basic understanding of Git and GitHub.
- Git installed on your local machine.
- A GitHub account.

## Lab Setup

1. **Clone the Repository by Following Steps in Your Assignment Description**


## Part 1: Branching

### Task 1: Create a New Branch
1. Make a file and name it assignment1.tx
2. Write a phrase in the file
3. Commit your changes
4. Push it to the remote repository
5. Make a pull request (You shouldn't merge your code. Keep the pull request open)

## Part 2: Rebasing
Checkout to the new-branch, which currently exists in the repository. Rebase this branch with the main branch.
